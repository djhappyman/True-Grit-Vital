# Stitch typography

The four `StitchNotoSans` runtime files are unchanged copies of the Noto Sans 2.015 fonts in the saved 20 October Stitch batch. The original export CSS specifies weights 400, 500, 600 and 700. They are registered under the application alias `StitchSans`; the original fonts and existing NotoSans family are preserved.
