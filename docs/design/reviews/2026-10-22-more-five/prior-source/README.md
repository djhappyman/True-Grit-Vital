# D18b prior panel source

Lead integration passed 31 combined prior-source, comparison, panel-detail and
trend-source checks. The current-panel return path uses encoded URI segments,
consistent with the shared source helper. Both theme captures were reviewed.

## Outcome

Each found earlier comparison on the canonical saved-panel detail now offers an
accessible `Open` action. It pushes the existing saved detail route for the
earlier panel through `supportingSourceLocation`, using the saved person and
record ids rather than the displayed title, date or value.

- The action appears only when the comparison is `found` with one real earlier
  point. None, incompatible, incomplete/ambiguous and truncated states show
  their existing factual message and no source action.
- Duplicate displayed values stay distinct: the route follows the selected
  earlier record and result identity. Two same-day values remain ambiguous and
  do not choose a source.
- The view stays read-only. Opening a source makes no draft, revision, void or
  storage write.
- The earlier detail receives the current panel detail URL as its `return`.
  That URL keeps the current detail's own return context, including the filtered
  Labs collection, so nested Back is restored. The current detail stays mounted
  beneath the pushed earlier record, preserving its result filter and page.
- Lock still hides the comparison and its action. A missing earlier record
  reaches the established unavailable state.

No sparkline or shared comparison helper was changed.

## Limits

- Host widget tests and synthetic captures only. Physical-device screen reader,
  measured performance and Android build evidence remain open.
- The result filter and page are retained because the current detail stays
  mounted under the pushed source. They are local view state, not route
  parameters, so a hard reload of the current detail starts from its defaults.
- Missing records are verified through the canonical saved route with an absent
  id; this slice adds no deletion or record lookup surface.
- Per-record superseded revisions remain available only through the existing
  audit view, not as comparison sources.
