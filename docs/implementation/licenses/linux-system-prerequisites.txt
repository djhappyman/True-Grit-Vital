Linux system prerequisites (local test build, 19 October 2026)

Vital invokes existing OS programs; none of these executables or their system
libraries is copied into, linked into, or redistributed in the Vital bundle.
No Dart/plugin dependency or downloaded native asset is added by this bridge.
The program boundary is replaceable at LinuxSecretStore. Do not package these
programs into a future installer without auditing that exact distribution and
carrying its complete licence/source obligations.

Audited host prerequisites:
- libsecret 0.21.8.2-1: secret-tool; LGPL-2.1-or-later.
  Versioned source and licence:
  https://github.com/GNOME/libsecret/blob/0.21.8.2/tool/secret-tool.c
  https://github.com/GNOME/libsecret/blob/0.21.8.2/COPYING
- GLib 2.90.1-1: gdbus; LGPL-2.1-or-later.
  https://github.com/GNOME/glib/blob/2.90.1/gio/gdbus-tool.c
  https://github.com/GNOME/glib/blob/2.90.1/COPYING
- util-linux 2.42.4-1: flock; its source is MIT. The wider OS package has
  mixed open-source licences, recorded in the package evidence.
  https://github.com/util-linux/util-linux/blob/v2.42.4/sys-utils/flock.c
  https://github.com/util-linux/util-linux/blob/v2.42.4/COPYING
- GNU coreutils 9.12-2: cat, install, chmod, sync; GPL-3.0-or-later.
  Documentation is GFDL-1.3-or-later, not the executable licence.
  https://github.com/coreutils/coreutils/blob/v9.12/COPYING
  https://github.com/coreutils/coreutils/blob/v9.12/src/install.c
  https://github.com/coreutils/coreutils/blob/v9.12/src/chmod.c
  https://github.com/coreutils/coreutils/blob/v9.12/src/sync.c
  https://github.com/coreutils/coreutils/blob/v9.12/src/cat.c

The running org.freedesktop.secrets provider is an OS service. This bridge
requires a usable Secret Service default collection and does not assume a
collection named login, create a keyring, change desktop settings, or accept
human-owned terms. Existing installed packages remain the system distributor's
responsibility, including their separately installed runtime libraries.

Exact installed versions, package-declared dependencies/licences, ownership and
SHA-256 hashes of each invoked executable are retained in:
docs/implementation/evidence/02-linux-storage/system-helpers.json
